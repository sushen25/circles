name: run-design-canvas
description: Build, render, screenshot, and check the Circles design canvas (docs/design, 78 .dc.html artboards generated by gen.py). Use when asked to run, regenerate, screenshot, render, view, or verify the design artboards or canvas.json, or to check that a gen.py change looks right.
---

Circles has no app code yet. The only runnable unit is the **design canvas**:
`docs/design/gen.py` generates 78 `*.dc.html` artboards plus `canvas.json`
(the manifest the canvas editor loads). Drive it with
`.claude/skills/run-design-canvas/driver.py`, which renders artboards to PNG
with headless Chrome, dumps their visible text, regenerates them, and checks
the committed HTML against the generator. All paths are relative to the repo root.

## Prerequisites

Verified on macOS 15 with Google Chrome 152 and Python 3.9.6 (system) and 3.14. Nothing to install:
the driver is stdlib-only and auto-detects Chrome at
`/Applications/Google Chrome.app` (or `google-chrome`/`chromium` on PATH;
set `CHROME=/path/to/binary` to override).

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --version
python3 --version
```

## Setup / Build

None. `gen.py` was patched so it writes next to itself instead of a hardcoded
`/home/claude/circles-design` (override with `CIRCLES_DESIGN_OUT=/some/dir`).

## Run (agent path)

Regenerate after editing `gen.py`, then render what you changed and look at it:

```bash
python3 .claude/skills/run-design-canvas/driver.py regen
python3 .claude/skills/run-design-canvas/driver.py shot Main InterestPrompt
```

PNGs land in `.claude/skills/run-design-canvas/shots/<Name>.png` (gitignored),
one per artboard at the size declared in `canvas.json`. **Open the PNG and look
at it** (Read tool); ~3s for one board, ~1s/board when batching.

| command | what it does |
|---|---|
| `list [--page P]` | artboards from `canvas.json`: name, page, size, title. Pages: `guest first organiser quiet native convert system` |
| `shot NAME...` | render named artboards (names are the file stem, e.g. `CircleHome`) |
| `shot --page quiet` / `shot --all` | render a page (7 boards ≈ 7s) or all 78, 4 in parallel (`--jobs N`) |
| `shot ... --out DIR --scale 2 --size 1400x1500` | change output dir, retina, or override the viewport |
| `text NAME` | visible text of one artboard, tags stripped (assert copy changes without a screenshot) |
| `regen` | run `gen.py` in place, then `git status` of `docs/design` |
| `check` | regen into a temp dir and diff against `docs/design`; exit 1 and list files on drift |

Examples that ran in this session:

```bash
python3 .claude/skills/run-design-canvas/driver.py list --page quiet
python3 .claude/skills/run-design-canvas/driver.py shot --page quiet
python3 .claude/skills/run-design-canvas/driver.py shot ConversionMap Components Emails
python3 .claude/skills/run-design-canvas/driver.py text Main
python3 .claude/skills/run-design-canvas/driver.py shot --all --out /tmp/circles-shots
python3 .claude/skills/run-design-canvas/driver.py shot Main --scale 2 --out /tmp/circles-retina
```

`shot --all` produced 78 PNGs at their `canvas.json` sizes; `--scale 2` gives 780×1688 for a phone board.

## Run (human path)

Open any `docs/design/*.dc.html` in a browser; it renders standalone (the
`./support.js` it references is supplied by the canvas editor and is not in the
repo). The canvas editor itself (the `design` skill's artifact) consumes
`canvas.json`; not exercised here.

## Test

There is no test suite. The check is that the committed artboards match the
generator:

```bash
python3 .claude/skills/run-design-canvas/driver.py check
```

Expected: `wrote 78 artboards` then `ok: docs/design matches gen.py output`.
Exit 1 with a `differs:` list means someone edited `gen.py` (or an artboard by
hand) without regenerating: run `regen` and commit the result.

## Gotchas

- **`gen.py` is the source of truth; the HTML is build output.** `regen`
  overwrites every `*.dc.html` and `canvas.json`, including edits saved from
  the canvas editor. When the skill was written, two committed boards
  (`CircleHomeConfirmed`, `CircleHomeDue`) lagged `gen.py` by a `white-space:nowrap`.
- **Headless Chrome never exits with a fresh `--user-data-dir`.** It writes the
  screenshot in ~2s, then spawns the Google updater (`UpdaterMain (--crash-handler)`
  in stderr) and hangs forever; `--headless` (old), `--no-first-run`,
  `--disable-background-networking` etc. do not help. The driver polls for the
  output file (or `</html>` for `--dump-dom`) and then SIGKILLs the process
  group. Do not call Chrome by hand without a watchdog. macOS has no `timeout`;
  `perl -e 'alarm shift; exec @ARGV' 30 "$CHROME" ...` works as one.
- **Chrome's default profile does exit** (3.8s) but that touches the user's real
  profile (it even tried to install the Gmail web app). Keep the isolation.
- **Fonts come from Google Fonts at render time** (`@import` in every board). Offline
  you silently get Georgia/system fallbacks; renders differ subtly (45266 vs
  45763 bytes for `Main`). Check the serif headline looks like Newsreader.
- **Screenshots are viewport-sized to `canvas.json` w×h**, not full-page. Boards
  whose content is taller (`ConversionMap` at 1400×1100) are clipped exactly as
  on the canvas. Use `--size WxH` to see the overflow.
- **`Main` is `Join` inside `gen.py`.** `gen.py` writes `Join.dc.html`, copies it
  to `Main.dc.html`, then deletes `Join.dc.html`. Do not add a board named `Join`.
- **Works with the GUI Chrome open** (separate profile per render, verified).
- **Chrome stderr noise is normal:** `CVDisplayLinkCreateWithCGDisplay failed`,
  `Trying to load the allocator multiple times`. The driver keeps stderr in a
  temp log it deletes; set `KEEP_CHROME_PROFILE=1` to keep it.

## Troubleshooting

- **`FileNotFoundError: '/home/claude/circles-design/Join.dc.html'`** running
  `gen.py` directly: an unpatched `gen.py`. The output dir must be
  `os.environ.get("CIRCLES_DESIGN_OUT", os.path.dirname(os.path.abspath(__file__)))`.
- **A hand-run Chrome command prints `NNN bytes written to file` and never returns**:
  the updater hang above. Kill it (`kill -9` the pid, plus children) and use the driver.
- **`TimeoutError: chrome did not produce output within 30s`**: the render itself
  failed; rerun with `KEEP_CHROME_PROFILE=1` and read the `chrome.log` path in
  the message.
- **`check` exits 1 with `differs:` lines**: run `regen`; the diff is the
  intended change if you edited `gen.py`, otherwise someone hand-edited HTML.
