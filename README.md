# Circles

Codename only — nothing in code, domains or store metadata should assume the
final name (architecture §5.4).

A small group keeps saying "we should catch up" and never does. Circles turns
one link, pasted into the group chat, into a real time in the diary: friends
mark the times they would genuinely be up for — **no account, no app, no
calendar access** — and the organiser confirms.

**Working here? Read [`AGENTS.md`](AGENTS.md) first.** It is short, and it is
the authoritative list of rules, commands and boundaries.

## Setup

Node 22 (see `.nvmrc`), pnpm 9 via Corepack, and Docker for the local database.

```bash
corepack enable
pnpm i
pnpm db:start     # local Supabase — Docker must be running
pnpm check        # everything CI runs; expect it to pass on a clean clone
```

Then:

```bash
pnpm dev          # Expo dev server; press w, i or a
```

Web works with no further setup. Native has caveats worth reading before you
start: [`apps/app/README.md`](apps/app/README.md).

## What is where

| Path                 |                                                                                   |
| -------------------- | --------------------------------------------------------------------------------- |
| `apps/app`           | the Expo universal app — web, iOS, Android from one codebase                      |
| `packages/domain`    | the product's rules as pure TypeScript, shared with the server                    |
| `packages/contracts` | Zod schemas for every boundary, the analytics catalogue, generated database types |
| `packages/tokens`    | design tokens generated from the canvas, and the two typefaces                    |
| `packages/config`    | brand constants, feature flags, environment schema                                |
| `supabase/`          | migrations, database tests, Edge Functions                                        |
| `docs/`              | the spec, the architecture, the ADRs, the design canvas                           |
| `docs/runbooks/`     | what to do when something breaks                                                  |

## Where it runs

|       | Supabase            | Web                        | Native                |
| ----- | ------------------- | -------------------------- | --------------------- |
| local | CLI stack in Docker | `pnpm dev`                 | development build     |
| dev   | hosted project      | EAS Hosting                | `development` channel |
| prod  | hosted project      | EAS Hosting, custom domain | `production` channel  |

Only **local** exists today. The hosted environments are set up in S0-11; the
deploy workflows are already written and wait on their secrets — see
[`docs/runbooks/ci.md`](docs/runbooks/ci.md).
