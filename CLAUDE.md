# CLAUDE.md

The rules for working in this repository live in **[`AGENTS.md`](AGENTS.md)**.
Read that file — commands, boundaries, the non-negotiables, the privacy
invariants and the definition of done are all there, and it is short enough to
read every time.

This file exists only so that Claude Code, which looks for `CLAUDE.md` by name,
finds its way there. Nothing is written here that is not in `AGENTS.md`: two
copies of a rule is one copy that will be wrong.

To change a rule, write an ADR — see "Changing a rule" in
[`AGENTS.md`](AGENTS.md#changing-a-rule).
